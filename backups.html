A backup runs automatically every day at about 5 am Calgary time. Each data group (orders, shops, rates, drivers, pay ledger, stops, scan log and so on) is emailed as its own file to the backup address. Not included, on purpose: login accounts and driver PINs, order photos, and the year-to-date cache.

Restore from a backup file

Choose one of the emailed files (.json.gz, for example scd-flower-orders-2026-10-22.json.gz). Nothing changes until you press a Restore button. By default only records that are missing are put back; existing records are never overwritten unless you tick the box.
